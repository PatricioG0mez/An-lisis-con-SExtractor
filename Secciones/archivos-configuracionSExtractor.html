Archivos principales de configuración

  • default.sex es el corazón de SExtractor. Contiene los parámetros globales del análisis; aquí se define el nivel de detección, el nombre del catálogo de salida y otros parámetros importantes.
  • default.param contiene la lista de parámetros que SExtractor medirá durante el análisis. SExtractor posee muchas propiedades observacionales disponibles.
  • default.conv contiene el filtro de convolución utilizado para mejorar la detección de objetos.
  • default.nnw corresponde al archivo de red neuronal utilizado para la clasificación estrella-galaxia.
